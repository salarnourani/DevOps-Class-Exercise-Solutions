# Print Numbers from 5 to 50 (Bash Script)

## Description
This Bash script prints all numbers from **5 to 50** on the screen in ascending order.

## Script File
print-5-to-50.sh

## How It Works
- The script uses a `for` loop.
- The loop starts from 5 and ends at 50.
- Each number is printed on a new line.

## How to Run

### Step 1: Give execute permission
chmod +x print-5-to-50.sh

### Step 2: Run the script
./print-5-to-50.sh

or

bash print-5-to-50.sh

## Example Output
5  
6  
7  
...  
49  
50

## Notes
- This script does not require any user input.
- It works with Bash shell.
