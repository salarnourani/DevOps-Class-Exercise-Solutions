# DevOps Class – Scripting Exercise Solutions

This repository contains Bash scripting solutions for DevOps class exercises focused on Linux system administration and automation.

---

## Prerequisites

- Operating System: Linux
- Shell: Bash
- Required tools: ping, scp, cut, find, date
- Some exercises require sudo privileges

---

## Exercises Overview

| Exercise | Title | Description | Script |
|--------|------|-------------|--------|
| 1 | Number Comparison | Compares an input number with 10 | exercise-1.sh |
| 2 | Min / Max Finder | Finds smallest and largest among 20 numbers | exercise-2.sh |
| 3 | Ping & SCP | Pings server and copies /etc/passwd if reachable | exercise-3.sh |
| 4 | Number Range | Prints numbers from 5 to 50 | exercise-4.sh |
| 5 | Passwd Backup | Daily backup of passwd fields + cleanup | exercise-5.sh |
| 6 | Logout Backup | Backs up HOME directory on logout | exercise-6.sh |
| 7 | Ping Scanner | Reads IPs from file and logs ping results | exercise-7.sh |
